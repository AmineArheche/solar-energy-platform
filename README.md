# ☀️ Solar Energy Platform — Plateforme Solaire Intelligente

Solution web professionnelle dédiée à l'évaluation, au dimensionnement et à la distribution d'installations solaires photovoltaïques au Maroc.

## 🌟 Fonctionnalités Clés
- ⚡ **Calculateur Solaire Régional** : Modélisation des rendements annuels et économies selon les données satellitaires solaires marocaines.
- 🛡️ **Architecture Sécurisée** : Protection contre les attaques CSRF, XSS et injections SQL avec requêtes préparées PDO.
- 📦 **Catalogue Équipements** : Gestion des panneaux, onduleurs hybrides et batteries à décharge lente.
- 📱 **Design Responsive** : Interface fluide adaptée aux mobiles, tablettes et écrans larges.

## 🚀 Démarrage Rapide
1. Clonez le dépôt et configurez le serveur Apache / Nginx.
2. Importez `energyprjt/database.sql` dans votre serveur MySQL.
3. Renseignez les variables d'environnement dans `energyprjt/config/database.php`.
4. Accédez à l'application via `http://localhost/energyprjt/`.
