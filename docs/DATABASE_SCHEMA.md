# Dictionnaire des Données — Base de Données Solaire

Tables principales :
- `users` : Comptes clients et administrateurs.
- `products` : Équipements photovoltaïques et caractéristiques techniques (puissance Wc, tension, garantie).
- `orders` : Commandes et devis solaires.
- `categories` : Classification (Panneaux, Onduleurs, Batteries, Accessoires).
