# Architecture Technique — Solar Energy Platform

## 1. Vue d'ensemble
L'application propose une suite intégrée pour l'ingénierie et la commercialisation de systèmes photovoltaïques au Maroc :
- Calculateur énergétique en temps réel (selon l'ensoleillement régional en kWh/m²/j).
- Catalogue et gestion de stock d'équipements solaires (panneaux, onduleurs, batteries).
- Espace client et suivi de devis / commandes.
- Backoffice d'administration sécurisé.

## 2. Pile Technologique
- **Backend** : PHP 8+ avec architecture modulaire et PDO sécurisé.
- **Persistance** : MySQL MariaDB (UTF-8 mb4 collation).
- **Frontend** : HTML5 sémantique, CSS moderne avec design tokens et Vanilla JavaScript optimisé.
